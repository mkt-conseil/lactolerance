## Mise en ligne avec GitHub Pages

1. Créer un dépôt (par exemple `lactolerance-proposition`).
2. Déposer **le contenu** de ce dossier à la racine du dépôt (`index.html` doit être à la racine).
3. Settings → Pages → Source : « Deploy from a branch », branche `main`, dossier `/ (root)` → Save.
4. La page est disponible après une à deux minutes à l'adresse
   `https://<votre-compte>.github.io/lactolerance-proposition/`.

À noter : avec un compte GitHub gratuit, le dépôt doit être public pour utiliser GitHub Pages ;
son contenu (page, PDF, vidéo) est alors consultable par toute personne qui le trouve.
Le fichier `robots.txt` et la balise `noindex` limitent le référencement, sans rendre la page privée.
